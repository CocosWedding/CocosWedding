# Coco's Wedding — Vercel

## Opción más sencilla: Vercel + GitHub

1. Crea un repositorio nuevo en GitHub, por ejemplo `cocoswedding`.
2. Sube `index.html` y la carpeta `public` completa.
3. En Vercel: Add New → Project → Import el repositorio.
4. Framework Preset: Other.
5. Build Command: dejar vacío.
6. Output Directory: dejar vacío.
7. Deploy.

Después puedes conectar `cocoswedding.com` desde Vercel → Settings → Domains.

Esta primera versión es una base visual. RSVP, galería colaborativa, recordatorios y regalos se pueden añadir después.
